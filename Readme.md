# Git Quiz

A simple web quiz that tests basic Git and GitHub knowledge.

## Purpose
This project is a simple quiz website that helps beginners test and review their
knowledge of basic Git and GitHub commands in a fun and easy way.
It was developed by a team of two to practice collaboration using Git branches,
pull requests and merges.

## Key Features
- Multiple-choice questions about Git and GitHub
- Instant feedback (green = correct, red = wrong)
- Final score at the end
- Restart button to try again

## Technologies
HTML, CSS, JavaScript (no libraries)

## How to Run
Download the project and open `index.html` in any browser.
